Mailbox Sorter

Sort your Gmail into boxes by dragging messages. Boxes here are Gmail labels, so they also show up in Gmail itself. Everything runs in your browser and nothing is sent to any server except Google’s.

One-time setup

  1. Open Google Cloud Console and create a project.
  2. Enable the Gmail API (APIs & Services → Library).
  3. Set up the OAuth consent screen: choose External, then add your own Gmail address under Test users.
  4. Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins, add
  5. Paste the Client ID below.
